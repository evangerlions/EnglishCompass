# English Compass 0.4.3

## What's New

- See grouped writing differences and ratings of the original text, with explanations for each answer.
- Close the current window with Command-W.
- Explore the native rich-text diff demo in Lab mode.

## Installation

Download `EnglishCompass-0.4.3-arm64.dmg` and drag English Compass into Applications.
Requires Apple Silicon and macOS 14 or later. Version 0.4.3, build 9.
Quit the older app before replacing it. Existing settings and API keys are retained.

## Verification

Built locally, signed with Developer ID Application, and notarized by Apple.
The DMG includes a notarization ticket. Credentials and API keys are not included.
See the accompanying SHA-256 file to verify the download.

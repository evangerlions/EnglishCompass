# English Compass 0.4.5

## Release Notes

- Fix selection shortcuts using stale input when the assistant window is already open.
- Keep the existing window position when processing the latest selection.

## Installation

Download `EnglishCompass-0.4.5-arm64.dmg` and drag English Compass into Applications.
Requires Apple Silicon and macOS 14 or later. Version 0.4.5, build 11.

## Distribution

Built locally, signed with Developer ID Application, and notarized by Apple.
The DMG includes a notarization ticket. Credentials and API keys are not included.

# English Compass 0.4.0

## What's New

- Choose the writing target language in Settings: English, Simplified Chinese, Hindi, Spanish, Arabic, French, Bengali, Portuguese, Indonesian, Urdu, Japanese or Korean. English remains the default.
- Get two candidates: a general version and an alternative with an improvement strategy chosen by AI. The second card shows its revision direction.
- See error corrections in **bold** and expression improvements in *italics*. Copy and replacement keep plain text.
- Translate input into the selected language instead of polishing it in its original language.
- Make Copy buttons readable when the window loses focus, with a visible label and clearer contrast.
- Keep target-language preferences separate in Lab mode, and use a matching macOS voice for answers when available.

## Installation

Download `EnglishCompass-0.4.0-arm64.dmg` and drag English Compass into Applications.
Requires Apple Silicon and macOS 14 or later. Version 0.4.0, build 6.
Quit the older app before replacing it. Existing settings and API keys are retained.
Understand English continues to translate English into Chinese.

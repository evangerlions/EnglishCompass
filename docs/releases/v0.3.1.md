# English Compass 0.3.1

## What's New

- Show English Compass in the Dock for easier access.
- Keep assistant windows open when switching to another app.
- Restore existing windows when reopening from the Dock.
- Give Lab its own app identity and icon; isolate test preferences from the live Lab configuration.

## Installation

Download `EnglishCompass-0.3.1-arm64.dmg` and drag English Compass into Applications.
Requires Apple Silicon and macOS 14 or later. Version 0.3.1, build 4.
Your existing settings and API key are retained when replacing the app.

## Verification

Built locally, signed with Developer ID Application, and notarized by Apple.
The DMG includes a notarization ticket. Credentials and API keys are not included.
The automated suite and release session smoke test passed.
See the accompanying SHA-256 file to verify the download.

# English Compass 0.4.7

## Release Notes

- Preserve headings, lists, and paragraphs in translation results.
- Improve line spacing for original text, translations, and explanations.

## Installation

Drag English Compass into Applications. Requires Apple Silicon and macOS 14 or later.
Version 0.4.7, build 13.

## Distribution

Built locally, signed with Developer ID Application, and notarized by Apple.
The DMG includes a notarization ticket. Credentials and API keys are not included.

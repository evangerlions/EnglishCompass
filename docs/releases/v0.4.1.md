# English Compass 0.4.1

## What's New

- Preserve partial text selections instead of accidentally processing the entire input field.
- Use normal assistant windows and hide the Dock entry when all assistant windows are closed. Menu bar access and global shortcuts remain available.
- Remove Replace buttons from results; copy the answer you want to use.
- Clarify AI instructions for bold error corrections and italic expression improvements.

## Installation

Download `EnglishCompass-0.4.1-arm64.dmg` and drag English Compass into Applications.
Requires Apple Silicon and macOS 14 or later. Version 0.4.1, build 7.
Quit the older app before replacing it. Existing settings and API keys are retained.

## Verification

Built locally, signed with Developer ID Application, and notarized by Apple.
The DMG includes a notarization ticket. Credentials and API keys are not included.
See the accompanying SHA-256 file to verify the download.

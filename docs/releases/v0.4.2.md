# English Compass 0.4.2

## Release Notes

- Fresh signed and notarized rebuild of the latest main branch.
- No application behavior changes since 0.4.1.

## Installation

Download `EnglishCompass-0.4.2-arm64.dmg` and drag English Compass into Applications.
Requires Apple Silicon and macOS 14 or later. Version 0.4.2, build 8.
Quit the older app before replacing it. Existing settings and API keys are retained.

## Verification

Built locally, signed with Developer ID Application, and notarized by Apple.
The DMG includes a notarization ticket. Credentials and API keys are not included.
See the accompanying SHA-256 file to verify the download.

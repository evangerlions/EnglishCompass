# English Compass 0.3.0

## What's New

- Return from results to the original input without losing your draft.
- Ask follow-up questions in a Markdown chat sidebar with the current input and result as context.
- Press Enter to submit in the main input and Question composer; Shift+Enter inserts a new line. IME composition does not submit.
- Drag the bottom grip to adjust and save the maximum window height.
- Syntax highlighting for raw JSON requests and streamed SSE responses in the inspector.
- Reduce scrollbar flashing while the result window grows.

## Installation

Download `EnglishCompass-0.3.0-arm64.dmg` and drag English Compass into Applications.
Requires Apple Silicon and macOS 14 or later. Version 0.3.0, build 3.
Configure your own Alibaba Cloud Bailian API key in Settings.

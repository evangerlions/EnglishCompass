# English Compass 0.4.4

## Release Notes

- Turn off Follow latest by default in the question sidebar.
- Bring an open assistant window to the front without resetting its contents or position.
- Preserve the last window position when reopening a hidden assistant window.

## Installation

Download `EnglishCompass-0.4.4-arm64.dmg` and drag English Compass into Applications.
Requires Apple Silicon and macOS 14 or later. Version 0.4.4, build 10.

## Distribution

Built locally, signed with Developer ID Application, and notarized by Apple.
The DMG includes a notarization ticket. Credentials and API keys are not included.

# English Compass 0.1.0

- Native macOS English writing and Chinese translation assistant.
- General, conversational and academic writing versions with brief explanations.
- Keyboard answer selection, plain-text copying and optional safe replacement.
- Bright blue app icon and drag-to-install DMG targeting `/Applications`.
- GitHub Actions performs tests only; signing takes place on the developer's Mac.

## Installation

Requires Apple Silicon (arm64) and macOS 14 or later. Open the DMG and drag
English Compass to Applications. Quit an older running version before replacing
it. Enter your own Bailian API key in Settings; no API key is bundled.
Cross-app reading/replacement needs your Accessibility permission.

## Signing Notice

The current `EnglishCompass-0.1.0-DeveloperID-arm64.dmg` is signed with Developer

service on October 15, 2026. The notarization ticket is stapled to the installer.

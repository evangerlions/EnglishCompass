# English Compass 0.2.0

- Choose a Qwen model in Settings; Qwen3.7 Flash remains the default.
- Stream writing and translation results as they arrive.
- Improve best-effort display of irregular responses and answer-card selection.
- Refine Markdown rendering and adaptive result-panel layout.
- Add a developer-only local Lab and multi-model benchmark tool.

## Installation

Requires Apple Silicon and macOS 14 or later. Quit English Compass, open
`EnglishCompass-0.2.0-arm64.dmg`, and drag the app into Applications.
Version: 0.2.0, build 2. Provide your own Alibaba Cloud Bailian API key in
Settings; model availability depends on your account. Cross-app reading and
replacement require Accessibility permission.

## Distribution

The published installer is Developer ID Application signed and notarized by
Apple, with a stapled notarization ticket. Signing and notarization credentials
remain on the build Mac; no credentials or API keys are included in the release.
The accompanying SHA-256 file verifies the final, stapled installer.

# English Compass 0.3.2

## What's New

- Show the app version and build number at the bottom left of Settings.
- Read version information directly from the installed app bundle so it stays accurate after updates.

## Installation

Download `EnglishCompass-0.3.2-arm64.dmg` and drag English Compass into Applications.
Requires Apple Silicon and macOS 14 or later. Version 0.3.2, build 5.
Quit the older app before replacing it. Your existing settings and API key are retained.

## Verification

Built locally, signed with Developer ID Application, and notarized by Apple.
The DMG includes a notarization ticket. Credentials and API keys are not included.
The automated suite and release session smoke test passed.
See the accompanying SHA-256 file to verify the download.
